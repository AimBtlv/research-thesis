## 2. How Was diri_lexical_list.csv Built?

**Digitised Extract of the Ancient Diri Lexical Series (Diri = (w)atru)**
This step extracts authentic, tablet-attested readings of sign compounds from a primary source: the ancient Sumerian lexical series Diri (ORACC/DCCLT).
The goal is to enrich the table of compound readings (Step 3). It is a direct quote from the ancient textbook. In this work it has the **second** reading priority, after @v (the reading values of a sign) in osl.asl: @v (OSL) → Diri → OGSL → Syllabary_CM. The pipeline must be able to answer one question reliably:
- How did Sumerian students read a specific sign combination, according to the very text used to teach them?

**The second stage of the pipeline is to extract Diri = (w)atru (MSL 15), ORACC/DCCLT**.
**Note**: What "Diri" Actually Means?
A **diri compound** is one whose reading is genuinely **unpredictable** from its components (e.g. |SI.A| is read diri, not si-a).
The `.` notation of `osl.asl` does not distinguish a diri compound from a plain sequence of signs: both are written identically (see Step 3).
**Note** **qcat (Q-catalogue)** is not a text corpus, but a service catalogue of ORACC, which tracks all composite texts (those marked with a Q-number, that is, "consolidated" versions reconstructed by scholars from several duplicate tablets) across the entire consortium at once, and for each such composite lists from which physical tablets (P-numbers) it was compiled.

## Data Sources
**ORACC / DCCLT** Digital Corpus of Cuneiform Lexical Texts. Publishes JSON editions of lexical texts. https://oracc.museum.upenn.edu/json/
DCCLT is a project within the ORACC consortium that digitises lexical and educational cuneiform texts (sign lists, syllabaries, word lists: what Sumerian scribes studied).

| Source | Description |
|---|---|
| **catalogue.json** | The DCCLT/signlists project catalogue (2,444 entries). A Diri text is identified by **two independent tags**: `subgenre` (used for individual tablet exemplars, e.g. `"OB Nippur Diri"`) and `series` (used for composite/score editions, e.g. `Q000146`, `series = "Diri"`). |
| **qcat.zip** | Global ORACC catalogue of composite texts (Q-number texts). No new texts resulted, but it confirmed the completeness of the exemplar-level search. |
| **Oracc JSON archives** | `dcclt-signlists.zip` (160 texts, with `catalogue.json`), `dcclt.zip` (main DCCLT project, 4,998 texts), `dcclt-nineveh.zip` (670 texts), `dcclt-ebla.zip` (156 texts). `dcclt-jena.zip` contains only catalogue and index files, no text editions, and is not used. |

**Download date:** September 2026. A second download (October 2026) gives the same 115 texts and 4,084 lines, but 3 lines differ, because Oracc has since edited the texts (`{d}KU₃.GI` → `{d}KU₃-GI`, `{d}KU₃.SUD` → `{d}KU₃-SUD`, `(<(A.X)>)` → `<(A-X)>`). The September version is kept as the reference, so that the numbers of Steps 3–5 stay reproducible.

## Pipeline Overview

| Stage | Task | Output |
|---|---|---|
| **Stage 1** | Filter `catalogue.json` for `subgenre` containing "Diri" **or** `series == "Diri"` | **233** catalogued Diri texts (223 found by `subgenre`, 10 more composite Q-texts found only by `series`) |
| **Stage 2** | Cross-reference the four archives against this list | **118** texts physically located; 3 of them are empty shells (catalogued, no transliteration yet) |
| **Stage 3** | Route each text by ID prefix: `P*` (tablet exemplar parser), `Q*` (composite parser) | **115** texts with content: 114 tablets + 1 composite |
| **Stage 4** | Classify each lemma by language and form shape, discard broken/ellipsis placeholders (`[...]`, `x`) | **4,084** lines extracted |

## Output Description

●	**`p_number`** — the CDLI/ORACC identifier of the source tablet (P-number) or of the composite text (Q-number).
●	**`designation`** — standard publication citation: how the tablet is cited in scholarly literature.
●	**`period`** — the tablet's period (Old Babylonian, Middle Babylonian, Middle Assyrian, Neo-Assyrian, Neo-Babylonian).
●	**`provenience`** — findspot, where recorded.
●	**`subgenre`** — the specific Diri recension this tablet belongs to.
●	**`line_label`** — tablet line reference, for citing back to the source (e.g. r i' 4').
●	**`sumerian_reading`** — attested Sumerian pronunciation (filled in 3,718 lines).
●	**`sign_sequence`** — the compound sign sequence (filled in 3,195 lines).
●	**`akkadian_gloss`** — accompanying Akkadian translation/equivalent, where preserved (filled in 3,361 lines).
