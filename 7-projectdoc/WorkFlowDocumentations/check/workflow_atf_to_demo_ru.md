## **3. Workflow (Пошаговый процесс)**

1. **ATF CDLI.** Строка с чтениями, например `1. a-na {d}suen-ma-gir`.
2. **Поиск знака для каждого чтения.** Каталог (`sign_catalogue_v13.csv`) и OSL дают знак, Unicode и глиф. К знаку добавляются сохранность (`#`, `[ ]`, `< >`, `<< >>`, `?`, `!`) и функция (LOGO / SYLL / DET / NUM / UNCLEAR). Результат: `gold_signs.csv` (gold) или `grapheme.csv` (весь корпус).
3. **Формат демо.** Каждая строка таблички становится цепочкой единиц `[глиф, чтение]`. Одна единица = одно чтение (составной знак e₃ = |UD.DU| становится одной единицей с двумя глифами). Повреждённые, восстановленные, добавленные издателем, лишние, нечитаемые знаки и знаки без глифа превращаются в разрыв (null), чтобы формула не «перескакивала» через лакуну.
4. **Поиск общих последовательностей.** Сравнение идёт по глифам, а не по чтениям: индекс биграмм → жадное расширение до максимальной общей цепочки.
5. **Анализ.** Формулы только в школе, только в практике и общие, по жанрам; сравнение с индексом Жаккара (общие знаки) и с распределением LOGO / SYLL.
